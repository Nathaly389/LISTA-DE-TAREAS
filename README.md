# Aplicación GUI: Lista de Tareas (Java Swing)

## Descripción
Esta aplicación permite gestionar una lista de tareas de manera visual. Se pueden añadir tareas, marcarlas como completadas y eliminarlas. Se desarrolló usando Java Swing.

## Funcionalidades
- Añadir nuevas tareas desde el campo de texto o presionando Enter.
- Marcar tareas como completadas (cambio visual a gris y tachado).
- Eliminar tareas seleccionadas.
- Doble clic en una tarea para marcarla como completada.
